# 句栖 · Debug 演示种子记录

> 用途：只在 debug 构建、虚拟机上复用，用来填满今日、我的、句库、回忆、省身、回信。
> 正式 release 不包含任何演示数据或种子代码。
> 初版记录：2026-11-14 / 1.0.4
> 日期不是固定值：种子代码用 Date.now() 计算，运行时整体后移。
> 文中 10 月 23 日–11 月 14 日只是初版示例，不是当前运行日期。

## 1. 复用方式

不要直接把种子代码留在正式工程里。步骤：

```text
1. 在 app/entry/src/main/ets/services/ 临时新建 DemoSeedV2.ets
2. 在 app/entry/src/main/ets/pages/Index.ets 的 Store.init() 后调用
3. 只在 own 为空、materials 为空时执行
4. 构建 debug，安装到虚拟机
5. 启动一次，确认数据写入
6. 删除临时种子文件和 Index 调用
7. 重新构建 debug / release
8. 用 install -r 覆盖安装，保留已写入的数据
```

调用位置：

```text
await Store.get().init(ctx);
const st = Store.get();
if (st.data.own.length === 0 && st.data.materials.length === 0) {
  await st.replaceAll(DemoSeedV2.build(), '');
}
```

不要用卸载重装保留种子数据；覆盖安装 `install -r` 才会保留。

## 10. 关联规则

```text
鼓励.bindIds = 对应旧事 id
旧事不需要反向存 bindIds，界面通过反向查询显示
句库.bindIds = 对应鼓励/旧事 id
```

界面可以取消关联：

```text
Store.toggleBind()
Store.toggleLibBind()
```
